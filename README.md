# 2FA Authentication Demo

Цей репозиторій містить демонстраційну програмну модель двофакторної автентифікації з використанням пароля та одноразового TOTP-коду.

Проєкт створено в межах кваліфікаційної роботи на тему:

**«Дослідження безпеки двофакторної автентифікації з використанням криптографічних токенів»**

## Мета проєкту

Метою проєкту є моделювання процесу двофакторної автентифікації та демонстрація роботи механізму перевірки користувача за двома факторами:

1. пароль користувача;
2. одноразовий TOTP-код.

Тестове середовище дозволяє показати, що для успішного входу до системи недостатньо знати лише пароль. Користувач також повинен ввести коректний одноразовий код, який генерується на основі спільного секретного ключа та поточного часу.

## Структура проєкту

| Файл | Призначення |
|---|---|
| `main.py` | Головний файл запуску програми з графічним інтерфейсом |
| `auth_server.py` | Модуль серверної перевірки автентифікації |
| `password_auth.py` | Модуль хешування та перевірки пароля |
| `totp_auth.py` | Модуль генерації та перевірки TOTP-кодів |
| `user_db.py` | Модуль зберігання тестових даних користувача |

## Основні можливості

- перевірка логіна та пароля користувача;
- генерація одноразового TOTP-коду;
- перевірка правильності другого фактора;
- заборона доступу при неправильному паролі або OTP-коді;
- моделювання захисту від повторного використання одноразового коду;
- демонстрація принципу роботи двофакторної автентифікації.

## Використані технології

- Python 3;
- стандартні бібліотеки Python;
- HMAC;
- SHA-256;
- TOTP;
- графічний інтерфейс на основі Tkinter.

## Запуск програми

Для запуску програми потрібно відкрити папку проєкту в Terminal і виконати команду:

```bash
python3 main.py
```
або:
```bash
python main.py
```
Залежно від налаштувань Python у системі.

## Призначення тестового середовища
Розроблена програма є навчальною демонстраційною моделлю. Вона не призначена для використання як готова промислова система автентифікації, але дозволяє дослідити основні принципи роботи 2FA, зокрема:
- взаємодію між користувачем і сервером автентифікації;
- перевірку першого фактора — пароля;
- перевірку другого фактора — одноразового коду;
- поведінку системи у випадку помилкового введення даних.
